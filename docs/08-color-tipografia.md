## Contraste

| Combinación | Ratio | Resultado |
| ----- | ----- | ----- |
| Texto (`#2B2B2B`) sobre Fondo Ivory (`#FAF8F5`) | 14.8:1 | **Pasa AAA** (Excelente legibilidad) |
| Acento Espresso (`#3A2321`) sobre Fondo Ivory (`#FAF8F5`) | 13.2:1 | **Pasa AAA** (Ideal para títulos) |
| Texto Blanco (`#FFFFFF`) sobre Principal Truffle (`#D8B4A6`) | 2.1:1 | **No pasa** (Usar texto Espresso `#3A2321` sobre botones Truffle) |
| Acento Espresso (`#3A2321`) sobre Principal Truffle (`#D8B4A6`) | 6.2:1 | **Pasa AA** (Apto para texto sobre botones) |

## Justificación

La elección cromática y tipográfica de **Studio Ash** busca transmitir una identidad visual de alta gama, calma y pulcritud dentro del rubro de belleza y extensiones de pestañas.

1. **Psicología del Color:** La combinación de tonos neutros cálidos (*Ivory* y *Truffle Blush*) transmite delicadeza, bienestar y cuidado personal. El *Espresso Brown* actúa como ancla visual para aportar estructura, lujo y asegurar el contraste necesario sin la agresividad de un negro puro.
2. **Jerarquía Tipográfica:** El uso de una tipografía *Serif* para encabezados resalta el carácter exclusivo y artesanal del servicio (*Lash Artist*), mientras que la fuente *Sans-serif* garantiza que las descripciones de servicios, precios y formularios sean altamente legibles en dispositivos móviles.
