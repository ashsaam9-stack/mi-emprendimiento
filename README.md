# Studio Ash — Sitio web

Estudio de belleza de la mirada en Valparaíso: extensiones de pestañas según morfología facial, lash lifting y depilación facial con hilo para piel sensible.
Incluye landing, blog y prototipo de reserva y tienda online.

> Proyecto de la **Evaluación Parcial 02 — Sitios Web y Landing Pages (DUOC)**.

## Uso de IA

- **Antigravity / Gemini:** Asistencia en la redacción estructurada de las especificaciones (`DESIGN.md`, specs de diseño y desarrollo), alineación de tokens tipográficos y estructuración de la matriz de QA y coherencia para la Fase 3.
- **Google Stitch:** Generación referencial de las pantallas en desktop y mobile a partir de los prompts de diseño y tokens del design system.
- **Ajustes manuales y criterio propio:** Definición del modelo de negocio de Studio Ash, selección de la paleta nude/rosa para clientas con piel sensible, priorización del flujo de reserva con abono del 50% y corrección de las discrepancias generadas por Stitch en la matriz de QA.
